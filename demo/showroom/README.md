# Marmix Flex · демонстрационный шоурум

Цель проекта — дать заказчику пройти путь от выбора фактуры до обработки заявки менеджером. Демонстрационная база SQLite содержит три стартовые позиции. Используйте вымышленные имена и телефоны.

## Запуск в Windows

Запустите `Start-Marmix.cmd` двойным щелчком и задайте пароль. Сервер работает, пока открыто окно запуска. Для работы из VS Code используйте PowerShell с Node.js 24 или новее:

```powershell
$env:ADMIN_PASSWORD = Read-Host 'Задайте пароль администратора (от 12 символов)' -MaskInput
npm.cmd start
```

Для PowerShell 5.1 без поддержки `-MaskInput` используйте встроенное окно безопасного ввода:

```powershell
$value = Read-Host 'Задайте пароль администратора (от 12 символов)' -AsSecureString
$env:ADMIN_PASSWORD = [System.Net.NetworkCredential]::new('', $value).Password
npm.cmd start
```

- Витрина: http://127.0.0.1:3100/
- Админ-панель: http://127.0.0.1:3100/admin
- Проверки: `npm.cmd test`. Устанавливать пакеты не требуется.

## Сценарий показа

1. Откройте каталог, выберите категорию, откройте «Азур».
2. Нажмите «Рассчитать материал», заполните форму тестовыми данными.
3. В админке откройте новую заявку, переведите её в работу, сохраните заметку и проверьте историю.
4. Добавьте товар черновиком, опубликуйте, отредактируйте и удалите его. У заявки сохраняется название материала, даже если товар удалён.

## Устройство

- `server.mjs` — маршруты, обработка форм, доступ в админку.
- `db.mjs` — схема SQLite и начальные демонстрационные данные.
- `views.mjs` и `style.css` — серверные HTML-страницы и оформление.
- `test/showroom.test.mjs` — интеграционные тесты обработчика HTTP и хранения.
- `data/showroom.sqlite` — локальные данные. Папка исключена из Git.
- Фотография интерьера взята из существующего проекта, карточка «Азур» использует изображение исходного сайта. Для остальных позиций предусмотрены декоративные образцы до добавления фото через админку.

## Размещение

Для отдельного доступного по сети показа нужен Node.js-сервер с постоянным диском и HTTPS-прокси. `HOST=0.0.0.0`, `PUBLIC_ORIGIN=https://адрес-показа`, `DATABASE_PATH` указывает на файл на постоянном диске. `ADMIN_PASSWORD` передаётся через переменные окружения. Веб-сервер нельзя выставлять напрямую за пределами HTTPS-прокси. Репозиторий и GitHub Pages сами по себе не запускают Node.js и SQLite. Демо работает независимо от Supabase и базы действующего магазина.

Перед приёмом реальных заявок подтвердите ассортимент и фотографии, согласуйте форму и документы об обработке персональных данных, настройте рабочее хранилище и резервное копирование.
