## Confirmed panel conversion and order validation

- Для **226 SKU** из шести названных категорий: `quantity sheets × 4.0328 m² × owner-confirmed price per m² = unrounded total`. Цена умножается на **4.0328**, не на отображаемое округление **4.03**. Округление итоговой денежной суммы определить только в будущей реализации; здесь способ денежного округления не назначен. Для 206 из этих панельных SKU известна фиксированная цена, а 20 пока имеют диапазон.
- 14 SKU «Гибкая доска» сохраняют `м²` как price/sale basis и `1 sheet` как минимум/шаг, однако **не используют** эту формулу без площади своего продаваемого формата.
- Неназначенный availability допускает каталог и Product Detail без текста о наличии, но запрещает add-to-cart и order submit. После назначения `in_stock` или `on_order` через Custom Admin товар становится кандидатом для заказа при условии заполнения цены, единицы и формата. Server-side validation перед созданием заявки повторно проверяет реальный статус и коммерческие параметры. Пока всем 251 SKU статус не назначен, **ни один не становится orderable лишь из-за этого подтверждения политики**.
- Slug остаётся независимым от SKU: два товара «Калаката» не объединяются, а public slug вида `kalakata-mf-mar-xxxx` **не утверждён**. Автоматическая генерация slug для устранения коллизии запрещена.

## Remaining Blockers

1. **Гибкая доска — 14 SKU.** Размер/площадь её продаваемого листа пока неизвестны. Расчёт `лист → м² → итог` для неё BLOCKED. Размер 142 × 284 см / 4.0328 м² **не переносить** на доску.
2. **20 SKU с диапазоном SOURCE PRICE.** Нужна точная фиксированная цена/вариант либо явно подтверждённое коммерческое правило; список ниже. Они INCLUDE, но пока без fixed-price commerce.
3. **11 сопутствующих материалов.** Подтверждены суммы опубликованных цен, но price unit, sale unit, minimum и step неизвестны. Панельный размер им не назначается, правило `м² / 1 sheet / 1 sheet` не применяется.
4. **Две группы public slug collisions.** Два разных товара «Калаката» делят `kalakata`; три акриловых покрытия имеют одинаковый усечённый legacy slug `finishnoe-pokritie-akrilovoe-dlya-gibkog`. Уникальные public URLs/модель вариантов остаются решением владельца, **не** автоматическим добавлением SKU к slug.

**Availability больше не является неопределённой политикой или пятым контентным блокером.** До будущего заказа каждый SKU по-прежнему должен получить явный рабочий статус через Admin; до этого он видим, но не покупаем. Это обязательная server-side validation, а не незакрытое решение о поведении.

**Не блокируют новую идентичность:** 20 расхождений старых DOM ID и URL ID (6 травертинов, 14 керамик) сохранены в [исходном evidence](CONTENT_FACTS.md#уточнения-и-расхождения) и [таблице конфликтов](CATALOG_OWNER_REVIEW.md#conflicts-requiring-owner-decision). У каждого из этих 20 теперь свой неизменяемый SKU, привязанный к URL ID. Повторная сверка старой платформы нужна только если появится конкретное расхождение контента/вариантов; не переименовывать SKU по DOM ID.

## Gate for future implementation

226 панельных SKU имеют подтверждённую **точную** площадь, но 20 из них без фиксированной цены; 14 гибких досок и 11 аксессуаров требуют отдельных коммерческих полей. Product Detail для двух slug-коллизий не выпускать под неуникальным маршрутом. Cart/Checkout должны считать только из подтверждённых значений, проверять текущую цену и availability на сервере, исключать add-to-cart/order submit для неназначенного статуса. Сумма для панелей: `sheets × 4.0328 × ₽/м²`; порядок денежного округления выбрать при реализации, не подменяя площадь `4.03`. T008 остаётся BLOCKED четырьмя пунктами выше, T009 не начинается.
