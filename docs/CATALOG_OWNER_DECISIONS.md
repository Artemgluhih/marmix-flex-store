## Launch Scope — доступные массовые решения

Сейчас **251 × UNDECIDED**, без автоматического изменения CSV.

- **INCLUDE ALL:** включить все 251 исходную позицию; затем отдельно решить совпадения, варианты, цены и поля для заказа.
- **INCLUDE CATEGORY:** выбрать одну или несколько из восьми групп и включить все их позиции; исключения указать через Legacy source ID.
- **EXCLUDE CATEGORY:** вывести все позиции выбранной группы из launch; не удалять их исходные строки.
- **INCLUDE INDIVIDUAL EXCEPTIONS:** дополнить правило списком точных Legacy source ID (или отдельных вариантов после решения конфликтов).

Комбинированное решение допускается, например «включить категорию, кроме ID …». До явного ответа ни один вариант не принят.

## Suggested SKU format — предложение

`MF-<CATEGORY_CODE>-<NUMBER>`: неизменяемый код группы при первичном создании SKU и последовательный четырёхзначный номер. **Коды предложены, ещё не утверждены:**

| Canonical category (proposed) | CATEGORY_CODE (proposed) |
|---|---|
| Гибкий мрамор | `MAR` |
| Гибкая доска | `BRD` |
| Гибкая керамика | `CER` |
| Травертин | `TRV` |
| Флюиды | `FLD` |
| Блоки | `BLK` |
| Гибкий камень | `STN` |
| Сопутствующие материалы | `ACC` |

**Примеры формата, не назначение существующим товарам:** `MF-MAR-0001`, `MF-TRV-0001`, `MF-ACC-0001`. Номер не зависит от названия или slug, не переиспользуется. При переименовании или смене категории уже назначенный SKU сохраняется (включая исходный код), чтобы связи с заказами не ломались. Разные продаваемые варианты требуют решения, один это SKU или несколько. Старый slug, Tilda ID и DOM ID **не считаются SKU**. Массовая генерация не выполнялась.

## Exceptions requiring a separate answer

- **20 несовпадений DOM ID ↔ URL ID:** 14 «Гибкая керамика», 6 «Травертин»; полный список пар и ссылок — [Conflicts requiring owner decision](CATALOG_OWNER_REVIEW.md#conflicts-requiring-owner-decision).
- **Две «Калаката»:** одинаковые имя и slug, разные старые ID; решить, это дубль, варианты или самостоятельные товары.
- **Три акриловых покрытия:** разные упаковки, но одинаковый усечённый slug; решить, это отдельные товары или варианты, и дать уникальные новые slug там, где нужно.
- **Срок службы:** конфликт опубликованных заявлений 25/30 лет; до подтверждения не переносить в товарные свойства.
- **Источник цены/единицы:** «Яшма» + 11 сопутствующих материалов без подписи единицы, 20 карточек с ценой-диапазоном. Не распространять правило 239 карточек автоматически.
