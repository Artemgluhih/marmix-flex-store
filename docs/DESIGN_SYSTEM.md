# Marmix Flex — Design System / Dark Gold Showroom

**Статус:** визуальное направление и прототип утверждены владельцем проекта фразой «ВИЗУАЛ УТВЕРЖДЁН», 24.09.2026. Этот документ — source of truth для визуальной реализации Redesign v2. Он не утверждает архитектуру приложения, состав каталога, цены и новые страницы.

**Источники:** [DESIGN_DIRECTIONS.md](DESIGN_DIRECTIONS.md), [утверждённый прототип](../prototype/index.html), его [стили](../prototype/styles.css), [поведение](../prototype/script.js) и [медиа](../prototype/assets/); [проверенный HTTPS preview](https://htmlpreview.github.io/?https://github.com/Artemgluhih/marmix-flex-store/blob/a873fa3c12b9a3be4b6120e468a64e6340220a58/prototype/index.html). Приложенный исходный визуальный референс задавал направление; итоговый прототип задаёт конкретную композицию. Прежняя пометка «предложение» в DESIGN_DIRECTIONS.md относится к состоянию до утверждения.

**Приоритет при расхождении:** видимый утверждённый прототип → его фактический CSS/HTML → этот документ → ранние ориентиры DESIGN_DIRECTIONS.md. Если правило ниже кажется несовместимым с прототипом, сохранять вид прототипа и согласовать правку документа до изменения visual language.

**Граница:** Header, Hero, Material Showcase, фрагмент Catalog, Product Card, application block и CTA имеют утверждённый визуальный образец. Изображения, декоры и цены прототипа демонстрационные; они не становятся товарами или подтверждёнными обещаниями бренда.

Основные пары text-primary, text-secondary, gold, success и error на graphite проверены на читаемость; для новых сочетаний нужен контрастный контроль на реальном фоне.

## 2. Typography

**Display:** Prata Regular 400 с поддержкой кириллицы. **Интерфейс:** Manrope 400/500/600/700 с поддержкой кириллицы. Прототип загружает их через Google Fonts и визуально использует именно эти гарнитуры; production-совместимый путь — локально обслуживать разрешённые лицензией файлы тех же семейств и нужные кириллические начертания. Смена гарнитуры требует отдельного согласования. Курсивные акценты в прототипе используют Georgia Italic как локальное дополнение к Prata, не новый стиль заголовков. Системные запасные семейства — Georgia/Times New Roman для display, Arial/sans-serif для UI.

Размеры ниже — референс существующего CSS. Адаптивные выражения показывают диапазон; для новых функциональных экранов сохранять характер, при необходимости повышая размер длинного текста до читаемого уровня, не уменьшая H1 и цену ради плотности.

## 3. Grid and spacing

**Фактическая рамка прототипа:** page shell максимум **1800px**; секции могут показывать изображение на всю эту ширину. Внутренний отступ desktop — **clamp(22px, 5.4vw, 82px)**, то есть около 78px при viewport 1440; полезная ширина там около 1284px. Не вводить глобальный фиксированный контейнер 1440px поверх утверждённого кадра. Широкие изображения и узкие текстовые колонки регулируются отдельно: Hero copy максимум 700px, supporting text около 350–420px.

| Уровень | Сетка / поля / gutter | Поведение |
|---|---|---|
| Desktop >1120px | Логическая 12-колоночная ось для новых разделов; поле по формуле выше; gutter обычно 20–28px. | Сохранять фактические пропорции блоков: Showcase 1.43:1 с gap 20px и смещением второго кадра 86px; Catalog 3 равных карточки с gap 21px; application block 1.2:1. Hero — интерьерный кадр с текстом слева. |
| Tablet 801–1120px | Логическая 6-колоночная ось, поле по той же формуле, gap примерно 16–20px. | Навигация и карточки уплотняются; при ≤1120 в карточке цена и действие могут встать друг под другом. Не сохранять три узкие карточки любой ценой. |
| Compact 621–800px | Поле 24px, логическая 6→4 колонки, основной рассказ один столбец. | Header 72px и меню; Hero разделяет фото сверху и текст ниже; секции дают паузу около 84–87px. |
| Mobile ≤620px | Поле 20px (ориентир 18–22px), логическая 4-колоночная разметка для выравнивания, основной поток и каталог фактически по одному столбцу; gap каталога 22px. | Товарное изображение остаётся крупным, цена и действие читаются вместе; изображение Hero над заголовком. При ≤370px есть запасной перенос цены и действия. |

В прототипе Intro имеет вертикальные отступы около 96px desktop и 60–64px mobile; Showcase/Catalog около 113–124px desktop и 80–87px mobile; application block около 125px desktop и 80px mobile; CTA около 75px desktop и 60–70px mobile. Это ритм крупных историй, а не требование делать каждую будущую форму высотой в экран. Внутри карточки: image → info 21px desktop / 19px mobile; price row отделён 1px линией, 18–21px от названия.

**Рабочая шкала интервалов для новых элементов:** 4, 8, 12, 16, 20, 24, 32, 40, 48, 64, 80, 96, 120px. Это нормализация встречающихся в прототипе расстояний, а не повод перенастроить его пиксель в пиксель. Расстояния 13, 19, 21, 23, 75, 87, 113 и 125px в утверждённом прототипе сохраняются там, где они уже заданы.

## 4. Component language

Таблицы разделяют **reference** (виден в прототипе) и **extension** (ещё не показан; его внешний вид выводится из утверждённых поверхностей и контролов). Новую функциональность и содержание проектировать отдельными задачами. Для всех интерактивных элементов: видимый focus-visible 2px gold с offset 4px, управление с клавиатуры, состояние не определяется одним цветом. Неприменимое состояние отмечено «—».

## 5. Imagery

- **Интерьер:** крупная архитектурная сцена, в которой поверхность занимает заметную реальную плоскость; мебель и свет дают масштаб. Кадр спокойный, cinematic light тёплый, но не янтарный фильтр на весь сайт. Визуализацию называть визуализацией, выполненный проект — проектом только после подтверждения.
- **Макрофактура:** плоскость без рамки, рук, искусственного блеска или декоративного объекта; мягкий нейтральный свет, видимый реальный рисунок. Сравнение фактур строится при сопоставимом масштабе и световом балансе.
- **Товар:** первое изображение показывает именно продаваемый вариант под нейтральным светом; второй кадр может показывать материал в интерьере. Не использовать сгенерированные в прототипе Ivory Vein, Graphite Vein и Warm Strata как реальные SKU.
- **Crop:** desktop Hero широкий около 16:9 (файл 1672×941), в прототипе точка фокуса справа; затемнение слева поддерживает текст. Mobile вместо сжатого desktop показывает высокий кадр сверху и самостоятельный текст ниже; фокус поверхности сохраняется. Нельзя перекрыть основной рисунок заголовком.
- **Пропорции:** Product Card 1.1 desktop / 1.23 mobile по CSS aspect-ratio; Showcase интерьер около 1.39, macro около 0.95 desktop и 1.17/1.34 mobile; application image широкий desktop и около 1.1 mobile. Допустимая вариация под конкретное фото не должна ломать ритм пары и товарного ряда.
- **Обработка:** в интерьерном кадре возможны тёплый свет и глубокие тени; на product/macro — достоверный цвет и белая точка. Не искажать оттенок товара ради атмосферы, не переносить затемнение Hero на образец. Указывать alt и контекст изображения; lazy loading вне первого экрана.

## 6. Motion

| Случай | Фактический референс / правило |
|---|---|
| Easing | Обычные действия: ease; фото товара: cubic-bezier(0.2, 0.7, 0.2, 1). Не использовать пружины, отскоки и бесконечные циклы. |
| Hero entry | Один вход фото 1.1s, scale 1.025→1 и opacity 0.3→1; текст 0.85s с задержкой 0.15s и сдвигом 14px. Это исключение для первой сцены, не базовая длительность всего UI. |
| Scroll reveal | Около 650ms, opacity 0→1 и translateY 16→0; IntersectionObserver однократно, threshold 0.08, без перехвата скролла. |
| Image reveal / gallery | Только при смене ракурса или появлении смыслового кадра; около 200–350ms для галереи; не чередовать случайные эффекты на каждом изображении. |
| Button / text hover | 200–250ms; gold hover и максимум −2px на primary; текст/линия меняют тон без свечения. |
| Card / image hover | Изображение товара 650ms и scale до 1.045; крупный интерьерный кадр 700–800ms и scale до 1.025. Цена и название статичны. |
| Parallax | В утверждённом прототипе нет. По умолчанию 0; добавление — отдельное визуальное согласование, если оно улучшает композицию. |
| Reduced motion | При prefers-reduced-motion: reduce убрать smooth scroll, transform/opacity entrance и длительные transitions; весь контент сразу виден, фильтр/меню/диалог работают. Без JS контент не прячется: класс motion-ready ставится скриптом. |

## 9. DO NOT

- Не превращать страницу в generic black/gold template, casino/barbershop/автомобильный luxury.
- Не заливать большие постоянные зоны золотом, не применять gold gradients, металлические блики и золото на каждом тексте, рамке или контроле.
- Не добавлять ряд одинаковых округлых карточек, glassmorphism, neon, глянцевые тени, SaaS dashboard эстетику и множество пиктограмм.
- Не менять самостоятельно Prata/Manrope/курсивный характер, пропорции заголовков или палитру. Не делать redesign утверждённых Header, Hero, Material Showcase, Product Card и CTA без отдельного разрешения владельца.
- Не скрывать цену, единицу, имя товара и основное действие до hover. Не подменять реальные характеристики, цены, отзывы, статусы, фото товаров и выполненные проекты демонстрационным контентом.
- Не переносить драматическую цветокоррекцию интерьерного Hero на нейтральный образец; не искажать цвет товара ради атмосферы.
- Не делать постоянную анимацию, навязчивый parallax, захват прокрутки и эффекты без поддержки reduced motion.

**Критерий проверки будущей страницы:** рядом с утверждённым Hero/Product Card/CTA она выглядит как часть одного showroom; фактура остаётся главным визуальным активом; коммерческая информация читается; тёмные уровни и золото распределены как в прототипе. Если для новой задачи этого документа недостаточно, сначала описать неоднозначность и запросить решение, а не менять направление молча.
