# Dark Gold Showroom — visual prototype

Откройте `index.html` в браузере или запустите локальный сервер:

```sh
cd prototype
python3 -m http.server 8000
```

Затем откройте `http://localhost:8000`.

Это **визуальный прототип фрагмента главной страницы**, а не действующий магазин. Три товара, их названия и цены демонстрационные; изображения сгенерированы для проверки визуального направления и не являются фотографиями товаров либо реализованных проектов Marmix Flex. Фильтр, меню и просмотр фактуры работают локально. Заказ, корзина и формы не подключены.
